## 1. Матмодель (З0)

### Состояние
- **Канва**: сетка ячеек-кубов; у каждой ячейки целевой цвет (включая «белый» — тоже цвет) либо пустота. Итог канвы = пиксель-картина, видна игроку целиком с первого кадра (end-state upfront). Канва разбита на **5 секций** [inf: по счётчику «x/5» в кадрах L12 «2/5», L1060 «0/5»]; прогресс секций = мелкий счётчик у рамки.
- **Свиньи-питатели**: единица ресурса = свинья {цвет k, ammo n}. ammo виден крупным числом над головой (5, 6, 10, 20, 31, 40, 50 — весь встреченный диапазон). Свинья проходит позиции: **резерв-очередь** (ряды под доками, частично скрытый) → **док на 5 слотов** → **конвейер-лента** вокруг поля → сошла (ammo = 0).
- **Конвейер**: замкнутая лента по периметру поля с фиксированным маршрутом (шевроны направления). Есть **capacity**: «push past the limit and you'll need to wait» (досье) — перегруз = простой, не штраф-метка.
- **Модификаторы на поле** (по мере уровней): ледяные мульти-HP блоки с видимыми числами (200, 80 на L675); цепи, связывающие свиней в резерве (L1060); «?»-свинья — цвет скрыт (L675, L704); рельсы-пути прямо на канве, свиньи-турели на них (L704); бокс-диспенсеры наверху поля (L1060); катерпиллары-носители (L704).
- **Мета**: номер уровня (наблюдено 12…1060), монеты (560…32.43k), 4 бустера с количествами (иконки: «+»-карта, рука, круговые стрелки, молоток; точные эффекты **[inf]** по иконкам), замки «Lv.14»/«Lv.18» на слотах бустеров в ранних уровнях.

### Действия
- **`tap_pig_send`** — тап по свинье в доке → прыжок на конвейер (если есть место; иначе ожидание) → лента довозит до колонки своего цвета → автоматический залп шаров своего цвета по канве, ammo падает за попадание. Целиться нельзя: «Pigs only hit their own color—no target-picking hassle» (досье).
- **Повторный тап по свинье на конвейере** — второй заход/залп: «when you tap again, it jumps back on the conveyor to fire another round» (досье).
- **`tap_booster`** ×4 (с расходом количества).
- Управления траекторией, свайпов, прицеливания нет — «one-tap control» (досье).

### Ограничения
1. **Capacity конвейера** — перегруз → простой (штраф временем).
2. **ammo конечен**, 0 → свинья уходит безвозвратно.
3. **Док = 5 слотов**; новый приходит только в освободившийся слот.
4. Бустеры конечны; часть заперта до уровня X.
5. Очередь прибытия ограниченно видима (нижние ряды видны, состав дальше — нет) **[inf]**.

### Общее горлышко
**Конвейер = место+время на ленте.** Все запуски соревнуются за одно окно обслуживания: сколько свиней одновременно крутится у канвы и кто следующий. Это тот самый ресурс, который `design_laws.md` (З2, З-БУФЕР) называет каноном («лента Pixel Flow — тот же закон (время)»). Вторичное горлышко — **ammo-дефицит цвета**: лёд «200» = нужно ~10 свиней по 20, т.е. консолидация очереди одного цвета.

### Победа / провал
- **Победа**: канва раскрыта/расчищена до конца (все секции). Финал = проявленная картина + разлёт кубов-конфетти (CPI-кадр shot1).
- **Провал**: явный предикат на кадрах не виден; по структуре — свиньи нужных цветов исчерпаны при незакрытой канве **[inf]**. Существует система продолжений: видео «Level 1060 | **No Continues** | Clean Gameplay» подаёт отказ от continue как особый режим ⇒ обычный режим имеет continue **[inf]**, почти наверняка за просмотр/монеты (жанровый стандарт; в досье рекламы нет — пробел источника, не подтверждение).

### Функция сложности (откуда берётся и растёт)
- **База уровня**: баланс Σammo по цветам ↔ число кубов соответствующих цветов (свинья «5»/«6» в L12 = доводка остатка, «50»×4 на L146 = масс-залив). 
- **Рост по осям**:
  1. **Длина расписания**: больше цветов × свиней → длиннее порядок запусков при 5 слотах.
  2. **Порядок arrivals**: очередь резерва — дизайн-инструмент; дефицит «нужного цвета сейчас» = форк «ждать освобождения / запускать неидеальную».
  3. **Плотность capacity**: чем больше желающих на ленту, тем дороже лишний запуск.
  4. **Мульти-HP (лёд 200/80)**: превращает «залп» в плановую консолидацию 5–10 свиней одного цвета.
  5. **Модификаторы связности**: цепи (запуск одного тянет/блокирует другого **[inf]**), рельсы на канве (время доставки зависит от пути), диспенсеры (подача свиней на поле).
- Сложность = **комбинаторика расписания при неполной видимости очереди** + ресурсные балансы. Моторики нет вообще — это головоломка очереди, замаскированная под шутер.

## 2. Кор-глагол + правила (реализм-фильтр З9)

Кор-глагол ровно один: **`tap_pig_send`** (тап по свинье = отправить в рейс; остальное — автоматика).

| # | Правило | Реализм (З9: «а так в жизни бывает?») |
|---|---|---|
| 1 | Тап по свинье = запуск на конвейер | Реалистично: посадка юнита на линию, очередь на обслуживание — фабричная логика. PASS |
| 2 | Свинья бьёт только свой цвет, автоприцел | Вне бытовой логики; условность жанра «цвет→цвет» (магнит). Держится тем, что правило едино и телеграфировано цветом everywhere. Условный PASS |
| 3 | Число над головой = ammo (счёт выстрелов) | Реалистично как «магазин/бак»: счётный расходуемый запас. PASS |
| 4 | Конвейер с capacity, перегруз = простой | Самый реалистичный узел: полоса пропускания конечна. PASS |
| 5 | ammo=0 → свинья уходит | «Отстрелялось — сошло с линии». PASS |
| 6 | «?»-свинья (цвет скрыт до запуска) | В жизни не бывает; формально — скрытая ставка (З4/З11), а не физика. Условный PASS |
| 7 | Лёд с числом (200/80) требует N попаданий | Реалистично: материал прочнее, больше работы. PASS |
| 8 | Цепи между свиньями, рельсы-пути | Физика цепи/рельсы реалистична (связанное не ходит свободно). PASS, но см. §6.5 (риск декорации по З7) |
| 9 | Свинья-пулемёт как образ | Антиреализм-карикатура (как птицы в Angry Birds). З9-нагрузку игры несёт не свинья, а **фабрика**: лента, слоты, магазин — вся модель читается метафорой «конвейер/очередь». Итог: PASS |

Вывод по З9: ядро честное — единственная антиреалистичная сущность (свинья) не является носителем правила сложности; правило сложности (очередь+capacity) реализмично.

## 3. UI / интерактив

- **Объёмы**: ammo = **крупные числа над юнитами** (не полоски); HP льда = числа на блоках (200, 80). Прогресс канвы = **само проявление картины** — лучший приём: итог виден с нулевого кадра, прогресс читается периферией без чтения. Секции = мелкий лейбл «2/5»/«0/5» у рамки — число-в-число, самое слабое место шкал (З6-нарушение: «цифра под цифрой»).
- **Полосок в UI нет вообще** — все ресурсы числовые, кроме канвы. Отсюда: у Paint Loop полоски/уровни жидкости — прямое улучшение над референсом (З6).
- **Цели**: канва-картина = цель и награда одновременно; отдельного текста цели на кадрах нет.
- **Касания**: одиночный тап, one-handed, «Quick sessions» (досье). Свайпов/hold/force-touch нет.
- **Аффордансы**: свиньи в позе прыжка лицом к полю; пустые слоты-гнёзда приглашают «посади сюда»; шевроны на ленте телеграфируют движение и направление; замки «Lv.X» на бустерах телеграфируют горизонт меты.
- **Что телеграфирует следующее действие**: на L12 — туториальный палец, указывающий свинью (ранний онбординг «тапай свинью»); далее телеграф держится на (а) числу льда («собери ещё N этого цвета»), (б) составу видимой части очереди, (в) свободным слотам ленты. **Подсветки «текущей зоны»/«следующего верного юнита» нет** — канва молчит, порядок придумывает игрок. Это главное UI-отличие от Paint Loop: у референса ноль навигации, вся навигация в голове.

## 4. Прогрессия / монетизация

- **Уровни 1000+** (наблюдено 12…1060), контентная лестница: L1–20 — 1–3 цвета, простые картинки, туториальный палец; L14/L18 — открываются слоты бустеров (замки на кадре L12); L95–146 — 4+ цветов, свиньи по 40–50, мелкий лёд; L675+ — лёд 200/80, «?»-свиньи; L704 — рельсы на канве, турели, катерпиллары; L1060 — цепи, диспенсеры, многосценовое поле.
- **Модификаторы уровней = фичи-слои** (лёд → «?» → цепи → рельсы → диспенсеры), каждые ~100 уровней свой слой **[inf: по наблюдённым точкам, кривая между ними не видна]**.
- **Экономика**: монеты (560 на L17 → 32.43k на L1060), кнопка «+» у счётчика монет = IAP-магазин **[inf по иконке]**; бустеры с количествами (4/10/10/9 на L146; 46/34/41/1 на L1060 — запас накоплен).
- **Rewarded-точки: в досье НЕ зафиксированы** — текст стора рекламы не называет. Видимые косвенные: система continues существует (см. §1) ⇒ точка «continue за просмотр» **[inf]**; выдача бустеров между уровнями/за прогресс **[inf]**. $140M lifetime IAP при такой структуре = классическая связка rewarded-бустеры + continue + coin-IAP **[inf, жанровый стандарт]**. Пробел досье отмечать как пробел, не как факт.

## 5. Сильные стороны (почему хит — по З1–З8)

1. **З1 (необратимые альтернативы)** — каждый тап невозвратно тратит ammo-носителя и слот ленты; при 5+ свиньях в доке «кого запустить» = выбор между альтернативами, а не подтверждение очевидного. 
2. **З2 (общее горлышко)** — лента с capacity: все решения (любая свинья, любой бустер ускоряющий) соревнуются за одно окно обслуживания. Это подтверждённый канон (`design_laws.md` прямо цитирует «ленту Pixel Flow»). Главный источник глубины игры.
3. **З3 (конечный ресурс + каскад)** — ammo кончается навсегда; дефицит цвета порождает каскад «ждать arrivals → держать слоты → консолидировать очередь на лёд 200» — дефицит рождает план, а не тупик.
4. **З-БУФЕР (порционная подача)** — док на 5 слотов + скрытый хвост очереди прибытия = эталонная реализация: игрок коммитит свинью, не видя весь поток; новое приходит только в освободившийся слот. `design_laws.md` уже записывает это как канон.
5. **З4 (скрытое = ставка)** — «?»-свинья и невидимый хвост очереди меняют план запуска (слабее, чем могла бы: см. §6.3).
6. **З6 (объём не цифрой)** — прогресс канвы = проявление картины, объём льда = число на самом объекте; состояние всегда «нарисовано на предмете». (Счётчик секций «x/5» — исключение, см. слабости.)
7. **З8 (механика читается из формы)** — число над свиньёй = заряд, шевроны = маршрут, лёд с цифрой = прочность, поза прыжка = «готова к запуску», дождь шаров = поток расхода. Каждая форма = инструкция.
8. **Доступность поверх глубины** — автоприцел убирает моторный барьер: глубина полностью в решениях (З1–З3), исполнение бесплатное. Сессия тапами 30–60 с, one-handed — жанровый стандарт выдержан; CPI-крючок «дождь шаров сносит пиксель-кубы» читается за секунду без слов.

## 6. Слабости / дыры

1. **КОРРЕКЦИЯ 2026-08-28 v2 (уточнение владельца: действие = ВЫБОР свиньи, никакого тап-запуска)**: лента бесконечна, свиньи сидят в буфере ~5 штук; игрок ВЫБИРАЕТ свинью — и она уходит красить свою зону по цвету. Ошибка выбора (не тот цвет / зона уже полна / рано) = свинья ПОТРАЧЕНА, слой с холста не снят, нужная свинья — дальше по бесконечной ленте. З5 выполнен: ошибка меняет состояние (буфер минус свинья, потребность висит). Спам невозможен — каждая свинья конечна.
2. **Числа-в-числах**: «2/5» секций поверх чисел ammo — ровно тот паттерн, против которого написан З6. Живого уровня ресурса (полоска/жидкость) нет нигде.
3. **«?» без цены**: скрытый цвет не привязан к ставке (нет штрафа за промах, нет стоимости раскрытия) ⇒ это сюрприз-конфетти, а не ставка в плане (З4/З11 выполнены наполовину).
4. **Провал размыт**: явный предикат провала не показан игроку; значит нет и драматургии «спасай уровень» перед FAIL (ср. Paint Loop §4: измеримый предикат → адресный оффер). Monetization-точка продолжения существует, но она не телеграфирована состоянием **[inf]**.
5. **Поздняя сложность = загромождение (З7-риск)**: цепи, рельсы, диспенсеры, катерпиллары — набор сущностей, а не углубление одного горлышка. Часть из них — посредники без собственного состояния (рельсы меняют только время доставки) — кандидат на З12-чистку.
6. **Пассивность 70% экранного времени**: прицеливание, движение и стрельба автоматические; игрок управляет только очередью. При видимой очереди и слабом дефиците это вырождается в кликер («просто посчитал» — анти-пример З-БУФЕР: «что игрок НЕ знает сейчас?» — если ответ «ничего», напряжения нет).
7. **Единая точка схождения**: у ленты один маршрут, ворота достижимы только им (нарушение З13) — congestion здесь работает только потому, что capacity маленькая; масштабирование сложности через З13-топологию не использовано.

### Отличия от Paint Loop (однострочно, для реестра)
- Подача: у Pixel Flow юнит = **связка «цвет+ammo»** (носитель расходуется целиком), у Paint Loop порция = единичный тап.
- Штраф: у ОБОИХ ошибка меняет состояние — Pixel Flow: свинья потрачена впустую выбором; Paint Loop (наш): перелив = −♥.
- Навигация: референс не подсвечивает цель (вся навигация в голове), Paint Loop ведёт подсветкой зоны.
- Объёмы: референс показывает числа, Paint Loop — полоски/уровни жидкости (З6).

## 8. Дизайн ассетов (vision-разбор просмотренных кадров)

База: shot1–6 (App Store), кадры L12, L675, L704, L1060 (YouTube-миниатюры). Всё ниже — видно глазами; оценки оттенков на глаз, без пипетки.

### 8.2 Форма-язык
- **Всё скруглено**: радиусы крупные — канва в «подкове»-рамке с внешним радиусом ~15% ширины экрана; слоты и ячейки-«гнёзда» = квадраты со скруглением ~25% стороны; бустеры = круги; пилюли = full-round. Острых углов нет нигде, кроме пиксельных ячеек.
- **Контраст «организмы vs сетка»**: живое (свиньи, катерпиллары) — бесконечно-гладкие капли/овалы; технологическое (ячейки, слоты, лёд) — сетка скругленных квадратов. Игрок отличает «существо» от «клетки» силуэтом.
- **Кубы** = скругленные квадраты с фаской: на маркетинговых кадрах фаска глубокая (виниловые кубы), на канве скругления мельче — та же форма в двух масштабах.
- **Обводок как контуров почти нет**: форма отделяется тенью по нижней кромке (ambient occlusion) и светлой кромкой сверху (1–2px highlight на тёмном UI). Исключение — цифры: белая заливка + тёмная обводка + тень, двойной контур ради читаемости на любом фоне.
- **Толщина масс**: рамка-конвейер — толстая «труба» (~8–10% ширины экрана), выглядящая как надувной/пластиковый рукав: светлая сверху, с синей тенью снизу, со швами-полосами у поворотов. Она же — дорожка, форма=функция (З8).

### 8.3 Шейдинг
- **Мягкий 3D, «виниловая игрушка»/claymation**: каждый куб — вертикальный градиент (светлый верх → насыщенный низ), мягкая граница света/тени, точка-блик сверху; никаких жёстких cel-shadow.
- **Глянец дозирован**: у обычных кубов — маленький specular; у ледяных блоков 200/80 (L675) — стекло: голубой градиент + крупный диагональный блик + светлая окантовка, материал «дороже» соседей (телеграф прочности материалом).
- **Свиньи** = латексные игрушки: подцвет тёмный, блик-полоса по спине, анатомия (нос, уши, хвост-завязка) прорисована складками-тенью, не контуром.
- **UI — «пластик с выдавливанием»**: пилюли и кружки с вертикальным градиентом + тёмная кромка-тень 2–4px снизу (готовое pressed-state) + мягкая отбрасываемая тень; у кругов бустеров — светлый обод.
- Состояния цветом: отработанные/чужие свиньи десатурируются до серого (L12 — серая «20» в резерве), активные — полная насыщенность.

### 8.4 Конструкция UI-элементов
- **Топбар**: круг-шестерёнка слева → пилюля уровня в центре (синяя на ранних, красно-оранжевая на L1060 — тема меняется с прогрессом) → монетная пилюля справа с приклеенной квадратной кнопкой «+» (IAP-вход встроен в счётчик).
- **Пилюли** — главный контейнер: «Level 12» (белый текст с тёмной обводкой на синем), монеты (иконка + число + «+»), уровневые подписи бустеров.
- **Бейджи-числа**: ammo — крупная белая цифра с тёмной обводкой прямо на теле свиньи, без плашки; HP льда — цифра на белой скругленной подложке поверх блока; счётчик секций «2/5»/«0/5» — маленький белый текст у левого нижнего угла рамки, без подложки (самый тихий элемент экрана).
- **Кнопки бустеров**: круги с белым глифом (карта «+», рука, цикл-стрелки, молоток) на цветной заливке; количество — маленький тёмный бейдж с белой обводкой в правом нижнем секторе круга; залоченный бустер = серый круг + иконка замка + подпись «Lv.14»/«Lv.18» белым.
- **Слоты** — тёмные скругленные квадраты с внутренней (inset) тенью: читаются как гнёзда-приглашения, пустота сама выглядит как «сюда можно».
- **Иконки** — белые монохромные глифы на цветном круге, единый вес линии; никакого мультицвета в иконках.

### 8.5 VFX-паттерны
- **Выстрел/полёт**: белый шар-комета с хвостом-росчерком (кадр L12 — белая дуга от свиньи-«31»); очередь шаров летит одной линией.
- **Попадание**: мелкие круглые частицы цвета куба + короткие вспышки; попадание своего цвета подсвечивает ячейку искрой.
- **«Готово» = искры**: на выполненных областях — жёлтые четырёхлучевые звёздочки-блёстки (вокруг планеты, shot4), state «сделано» читается sparkle-слоем.
- **Финал-ревел**: кубы разлетаются с вращением и конфетти (shot1 — облако кубов в воздухе) — тот самый CPI-кадр «дождь из кубов».
- **Пустая канва** — точечный pegboard-паттерн (сетка светящихся точек на тёмном): «дырчатая доска», в которую встанут кубы; состояние «здесь будет картинка» показано текстурой, не текстом.
- **Тени-привязки**: мягкая тень под каждой свиньёй и бустером; на ленте свиньи отбрасывают тень на трубу — юниты «стоят» на поверхности, не парят.
- **Туториал**: жёлтая cartoon-рука-указатель на раннем уровне (L12) — стандарт жанра, стилизован под общий пластилин-лук.

Вывод по ассетам: единый «винилово-конфетный» лук (мягкий 3D + дозированный глянец + полный отказ от контуров), вся читаемость построена на насыщенности против тёмного фона и на скруглении как единственной геометрии; форма несёт функцию (труба=дорожка, лёд=стекло, гнёзда=inset, серость=отработано) — ассетный слой дисциплинированно работает на З8, это одна из причин мгновенной читаемости в CPI.


## 9. ДИНАМИКА ГЕЙМПЛЕЯ ИЗ ВИДЕО (24 кадра Level 704, шаг 2с — 2026-08-28)
Механики, НЕВИДИМЫЕ в статике сторов — подтверждено кадрами f05/f09:

1. **Свиньи ЦИРКУЛИРУЮТ по изогнутым рельсам вокруг канвы** (верхняя/левая/правая
   кривые). За 10 секунд состава на рельсах полностью сменился: красный «10»
   (верх-лево) исчез, бирюзовый «20» появился, синий «2» стал «8» с рукой-курсором.
   Лента — живой карусельный конвейер, а не статичные слоты.
2. **Нижний ряд из 5 пустых слотов = буфер запуска** (З-БУФЕР канон). Свиньи из
   рельс попадают в слоты; запуск возможен только из слота.
3. **«?»-свиньи живут В ОЧЕРЕДИ** (фиолетовые «?» под слотами): цвет раскрывается,
   когда свинья входит в слот запуска. Ставка срабатывает в момент входа — З3/З-БУФЕР
   подтверждены видео, не теорией.
4. **Запуск авто-прицелен по цвету**: тап по свинье → она летит в свою цветную зону.
   Выбор свиньи = выбор, какую цветную потребность закрыть сейчас.
5. **Прогресс «N/5»** = закрытые регионы канвы (1/5 → 2/5 между кадрами).
6. Белые свиньи «20» — отдельный крупный объём (неокрашенный / базовый материал).
7. Инфраструктура: 16.87k монет, колокольчик, пара свиней соединена цепью
   (связанные объёмы = модификатор).

**Следствие для метода:** статичные скрины сторов показывают UI, но НЕ механику.
