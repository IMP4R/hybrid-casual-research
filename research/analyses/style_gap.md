# STYLE GAP: референсы vs наши кадры (исследование 2026-08-28, по прямым скринам)
Источники: research/screens/{sand_loop,marble_sort,pixel_flow}/, наши sr2_f1–f4.
Директива: «самое главное ориентироваться на стиль референсов», «слишком плоско»,
«куда делся рисунок попугая», «не по вращению пушки».

## ОШИБКИ ПРОМТОВ (почему вышло мимо) — по З и фактам
1. **Описывал СОСТОЯНИЯ, не ДЕЙСТВИЯ/АНИМАЦИИ** (З8, директива «промпт = правила,
   изложенные действиями», S4-спека не перенесена в промты). «Muzzle is now empty»
   вместо «пушка только что выстрелила: корпус присел от отдачи, из ствола вылетела
   плитка, у дульного среза вспышка, в стволе появляется следующая».
2. **Не задал вращение пушки** как факт геометрии кадра (F3: линия уходит влево,
   а корпус смотрит вправо — пользователь поймал сразу).
3. **Не задал КАРТИНКУ-ЦЕЛЬ** — распался на «12 кластеров» (п.1 матрицы). Канон
   референсов: игрок всегда видит попугая целиком (призрак), выстрелы его проявляют.
4. **Слова-плоскости**: «flat solid», «airy minimal» — буквальный заказ плоскости.
   Надо: градиент, AO-тень, specular, блик рамы, глубина.
5. **UI скопирован с чужого кадра**, а не с референсов (белые пилюли вместо тёмных).
6. **Не указан контраст «призрак vs проявленный»**: у топов бледное поле + сочная
   картинка. У нас призрак и заполненный различаются слабо (только в F4).

## ДЕЙСТВИЯ/АНИМАЦИИ, которые ДОЛЖНЫ быть в промте каждого кадра (из S4-спеки)
Кадр = МОМЕНТ действия, не диаграмма состояния:
- F1 ПРИЦЕЛ: пушка ЗАРЯЖАЕТСЯ (плитка поднимается из лотка в ствол — показать
  плитку наполовину вошедшей? нет: F1 = уже заряжена), линия-ломаная ПУЛЬСИРУЕТ
  (двойной пунктир + лёгкое свечение), палец с рябью НА пушке.
- F2 ВЫСТРЕЛ: ОТДАЧА (корпус присел на колёса), ДУЛЬНАЯ ВСПЫШКА, плитка на
  сегменте 2, шлейф из искр вдоль СВОЕГО сегмента, у звезды отскока — разлёт
  искр, пушка УЖЕ заряжает следующую (плитка наполовину входит в ствол).
- F3 РАСКОЛ: плитка РАЗБИЛАСЬ о дальнюю чужую: осколки с вращением разлетаются,
  ударная звезда, ✕ и «−1» с наклоном (тряска), ПРАВОЕ сердце гаснет (серое,
  треснувшее), пушка ПОВЕРНУТА влево на ~40° (корпус!, колёса на месте).
- F4 ПОБЕДА: последняя плитка ВПЕЧАТАЛАСЬ с лучами; ВСЕ воксели попугая сочные,
  глянцевые, с бликами; призрачности НЕТ нигде; LEVEL COMPLETE + конфетти падает;
  сердца = 2 (цена ошибки сохранена).

## Канон кадра после фикса (S6/S7 v2)
Небо-градиент → белая рама канвы (фаска, блик, AO-тень) → внутри на бледном поле
ПИКСЕЛЬ-ПОПУГАЙ из вокселей (пустые = призрак цвета, заполненные = сочные) →
под канвой пушка НА тени-полу → тёмные UI-пилюли сверху → лоток очереди снизу.
Геометрия рикошетов v2.1 НЕ меняется.
