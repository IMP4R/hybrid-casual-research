# Схема онтологической карточки механики v1

Карточка = атомарное описание кор-геймплея одной игры. Библиотека карточек → источник
для кроссовера и проверки правил. Файлы: `ontology/mechanics/<slug>.json`.

## Поля

| Поле | Смысл | Откуда |
|---|---|---|
| `game`, `publisher` | идентификация | досье |
| `market` | выручка/загрузки/тренд-ранг | games_seed.csv |
| `core.input_verb` | ЕДИНСТВЕННЫЙ кор-глагол игрока | кадры + видео-описания |
| `core.physics_material` | поведение вещества/объектов | кадры |
| `core.spatial_topology` | организация пространства уровня | кадры |
| `tension_vectors[]` | источники напряжения/проигрыша | кадры + гайды |
| `reward_loop` | juice + условие победы/фаза релакса | кадры |
| `modifiers[]` | модификаторы уровней (второстепенные механики) | поздние уровни в роликах |
| `meta_layer` | мета-прогрессия | скрины сторов |
| `session_shape_seconds` | цикл «напряжение→разрядка» | ролики |
| `browser_feasibility` | оценка переноса в Godot/WebGL: sim_type, draw_calls, риск | экспертная |
| `invariant_check` | прогон через правила R1–R5: pass/fail | детерминированная проверка |
| `evidence[]` | ссылки на конкретные кадры досье с пояснением | обязательна |
| `confidence` | 0–1 по блокам; <0.5 = гипотеза, требует кадров | честность |

## Правила-инварианты (детерминированный фильтр)

- **R1** — не предлагать force-touch ввод (нет на большинстве устройств)
- **R2** — ровно один кор-глагол; остальное = модификаторы уровней
- **R3** — векторы напряжения не должны взаимоуничтожаться без дизайн-ответа
  (релакс ≠ тикающий таймер)
- **R4** — шейдерные «до/после» эффекты не считаются геймплейной инновацией
- **R5** — браузерный бюджет: sim >500 физ. тел одновременно = CPU-риск,
  симуляция желательна shader-side
- **R6** — причинно-следственная связь НАРИСОВАНА в кадре: видимый путь от ввода
  к результату (траектория/стрелка/шланг), целевой объект подсвечен, правило
  цвета/порядка показано маркером на объекте (свотч цвета на зоне), а не в голове.
  Урок 2026-08-27: Paint Loop и Belt Jam без этого не поняли, Shot Painter
  (с траекторией) поняли.
- **R7** — конкретное взаимодействие с экраном показано: палец-курсор + тап-рябь
  на интерактивном элементе, подсветка выбранного объекта. Игрок должен видеть,
  ГДЕ трогать, без угадывания.

## Конвенция честности

Карточка с `confidence.core < 0.5` не участвует в кроссовере, пока не наберёт
минимум 3 независимых кадра. Каждое поле ядра должно иметь ссылку на evidence.
