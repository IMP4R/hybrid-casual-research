# Shot Painter — концепт ядра v1.0 (метод-цикл v1.1: один заход)
Г3. Скелет-источник сложности: «порядок-блокировки × порционная подача»
(канва-питатели + полёт по фиксированным маршрутам). Родня: Hexa Away (порядок),
Pixel Flow (питатели) — гибрид: 0 физики, тап-ядро, веб-идеален.

## S2. Матмодель ядра
**Состояние:** канва = сетка слотов (цвет-требование, позиция, заполнен/пуст);
пушка снизу (заряжена плиткой цвета); очередь следующих плиток; траектория
(ломаная с рикошетами от стен — фиксирована для каждой пары пушка→слот); сердца 3.
**Действие:** `tap_cannon_to_shoot` — выстрел заряженной плиткой по текущей
траектории; плитка летит, рикошетит от стен, и садится в ПЕРВЫЙ пустой слот
своего цвета на пути.
**Ограничения:** путь перекрыт уже стоящей плиткой → столкновение, плитка
РАЗБИВАЕТСЯ (−♥); на пути нет слота своего цвета → плитка улетает (−♥).
**Общее горлышко (З2):** общие коридоры — стоящие плитки блокируют траектории
других цветов ⇒ порядок выстрелов определяет доступность маршрутов (взаимная
блокировка решений).
**Усложнение-модификаторы:** вращающиеся отражатели, двойные слоты, «?»-плитки.
**Провал:** 0 сердец. **Победа:** все слоты заполнены.
**Функция сложности:** топология маршрутов × пересечение цветов в коридорах ×
порядок очереди.

**Анти-теорема пустоты (З0 ✓):** выстрел ставит плитку в слот на общем коридоре →
блокирует траекторию другой плитки ⇒ порядок выстрелов меняет доступность
маршрутов. Решения взаимодействуют — игра не вырождается.

## S3. Уровень L40 «Пушка и попугай» — математика (проверка кодом)
Сетка 6×6 (но занято 12 слотов): 4 цвета × 3 слота.
Пушка снизу-центр. Очередь плиток (12): B,B,O,O,G,G,R,R,B,G,O,R (интерливинг).
Слоты (цвет × позиции по канве): синие (1,1),(4,1),(2,4); оранжевые (5,2),(2,3),(5,5);
зелёные (0,3),(3,4),(1,5); красные (3,1),(4,4),(0,5).
Солвер (DFS): порядок выстрелов, при котором каждая плитка достигает слот
своего цвета без пересечения занятых клеток — проверяется перебором.
Выход скрипта: solvable True/False + найденный порядок.

## S4. Интерактив-спека (З8: форма = смысл = анимация)
| Объект | Форма-аффорданс | Key-анимации |
|---|---|---|
| Пушка | жерло с видимой заряженной плиткой | тап → отдача + плитка летит со шлейфом |
| Траектория | пунктирная ломаная с рикошетами | пульсирует при наведении на пушку |
| Слоты канвы | цвет-бейдж + объём | заполнение: плитка «впечатывается» + ✓ |
| Разбитая плитка | осколки цвета | разлёт + звезда удара + «−1 ♥» |
| Сердца ×3 | пилюля сверху | гаснет с тряской |
| Очередь | 3 полупрозрачные плитки справа | сдвиг при выстреле |

## Реализм-фильтр (З9): пушка в мастерской — реальный объект; плитки — керамические
чеканки. Проходит. Сессия 40–60 с; сложность через порядок, не через реакцию.

## v2.0 — ФИЗИКА ДАЛЬНЕЙ ЯЧЕЙКИ (коррекция пользователя 2026-08-28)
Предыдущая модель «плитка садится в первый цветной слот» ОТМЕНЕНА.

Состояние: прямоугольная канва со стенами; пустые ghost-ячейки; заполненные ячейки;
пушка с начальным вектором v (стрелка); плитка цвета c; сердца H=3.

Выстрел: луч x(t)=p+t·v. При столкновении со стеной с нормалью n:
  v' = v − 2(v·n)n
(угол падения = углу отражения). Никаких дуг — только прямые сегменты с острым
изломом ровно на границе стены.

Вдоль отражённого луча строится упорядоченный список достижимых пустых ячеек.
Плитка автоматически садится в ПОСЛЕДНЮЮ (самую дальнюю) ячейку списка.
Условие успеха: color(tile) == ghost_color(farthest_cell).
Несовпадение → плитка разбивается в дальней ячейке, −♥.

Горлышко: заполнение дальней ячейки меняет, какая ячейка станет дальней в следующем
выстреле. Поэтому каждый успешный ход перестраивает множество целей; порядок
цветов в очереди × геометрия рикошетов = головоломка.
