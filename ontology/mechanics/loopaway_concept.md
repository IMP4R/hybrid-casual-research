# Loop Away — концепт ядра v1.0 (Г4, метод-цикл v1.1: один заход)
Скелет-источник сложности (S1): **топология пересечений × порядок-блокировки**.
Доноры из библиотеки: yarn_loop (нити, распутывание, зачистка), hexa_away
(порядок снятия слоёв). НЕ пересекается с Г1-Г3: другой носитель (гирлянда),
другой кор-глагол (свап соседних), другая математика (пересечения хорд).

## S2. Матмодель ядра
**Состояние:** перестановка N бусин по окружности; пары бусин одного цвета
соединены хордами; ходы B. Пересечение двух хорд = **узел**.
**Действие:** `tap_swap_adjacent(i)` — обмен местами соседних бусин i, i+1.
Других действий нет (R2).
**Ограничения:** ходы конечны; хорды не тянутся вручную; узел убирается только
изменением порядка.
**Общее горлышко (З2):** каждый свап меняет пересечения ВСЕХ хорд вокруг —
решения взаимодействуют, эффект неаддитивен (теорема пустоты ✓: целевая функция
не распадается по цветам).
**Провал:** ходы = 0 при ненулевых узлах. **Победа:** 0 узлов (гирлянда
распрямлена). **Функция сложности:** число хорд × длина перемешивания × дефицит
ходов (бюджет − оптимум).
**Реализм-фильтр (З9):** распутать гирлянду/бусы/наушники — бытовой жест. ✓
**Модификаторы:** замороженные бусины (нельзя свапать), «?»-бусины (цвет виден
после первого свапа), цепи между бусинами. Всё — правила порядка, новых
глаголов не создают.
**Штрафы (паркованная директива UI-различий):** БЕЗ сердец. Ресурс = ходы
(точки на пилюле, З6). Ошибка сжигает ход и может создать новый узел; мгновенного
проигрыша нет — только 0 ходов.

## S3. Уровень L1 — математика (tools/rope_map.py, проверено BFS)
6 бусин (3 пары R/G/B), старт RGBRGB → **3 узла** (хорды-диаметры пересекаются
тройкой). BFS: оптимально **3 свапа** [(0,1),(1,2),(0,1)] → 0 узлов.
Бюджет **4** (1 лишний — обучающий запас). L100 по З-МАСШТАБ: 16+ бусин,
10+ пар, бюджет = оптимум+1, замороженные бусины.

## S4. Интерактив-спека (З8)
| Объект | Форма-аффорданс | Key-анимации |
|---|---|---|
| Бусина | глянцевая сфера с бликом, крупная | тап-свап: две соседние обмениваются пружинной дугой |
| Хорда-нить | слегка провисающая линия цвета пары | исчезновение узла: вспышка + ✓-искра на нити |
| Узел | перекрестие нитей | появление нового узла: «!» + дрожь бусин |
| Ходы | пилюля с точками | точка гаснет с ходом (З6: точки, не цифры) |
| Узлы-счётчик | пилюля «узлы: N» | pop при изменении; 0 = золото |
| Победа | гирлянда распрямлена | нити параллельны, LEVEL COMPLETE + конфетти |

## Рендер-канон (design_system v1.0)
Сеттинг: **вечерний пирс** — деревянный настил, причальные сваи с канатами,
тёплые фонари, маяк в дымке, лёгкая рябь воды. Круглая белая рама-венец
(гирлянда круглая — форма отличает от досок Г1-Г3). Материал клэй един.
