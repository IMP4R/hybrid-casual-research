# Pin Away — концепт ядра v1.0 (Г5, метод-цикл v1.1: один заход)
Скелет-источник сложности (S1): **порядок-открытия × сортировка потока**.
Рынок доказан: класс pull-the-pin — сотни миллионов загрузок (см. claim
c-9708-смежный аудит ниши untangle: тот же принцип «доказанный скелет +
обязательная дифференциация»). Дифференциация: необратимые штифты + цветовые
квоты + потеря ресурса (не сердца, не драг).

## S2. Матмодель ядра
**Состояние:** вертикальный канал из секций с кристаллами; штифты-заглушки
(золотые) держат секции; боковые отводы со своими штифтами; колбы-квоты снизу.
**Действие:** `tap_pull_pin(p)` — выдернуть штифт. НЕОБРАТИМО (З1 — сильнее
переключателей Г2). Гравитация сыплет всё, что держал штифт, вниз.
**Ограничения:** канал выходит в ОДНУ колбу своего цвета; чужой кристалл при
сливе = ПОТЕРЯ (выпал мимо); секция — это порядок: сыплется снизу вверх.
**Общее горлышко (З2):** порядок выдёргивания — единственная переменная; каждый
штифт меняет судьбу всех секций выше. Теорема пустоты ✓: решения не аддитивны.
**Провал:** квота недостижима (потеряны кристаллы своего/чужого цвета). **Победа:**
все квоты закрыты, потерь 0.
**Функция сложности:** число штифтов × степень перемешивания секций × ширина
отводов. **Реализм (З9):** выдернуть заглушку в руднике — бытовой жест. ✓
**Штрафы (директива UI-различий):** БЕЗ сердец. Ресурс = сами кристаллы
(потеря видима физически: упал на настил и разбился).
**Модификаторы:** ледяные штифты (нужно 2 тапа), штифты-краны (перекрывают
жёлоб), смеси из 3 цветов, квоты-таймеры (с L90 по З-СТЕНА).

## S3. Уровень L1 — математика (tools/pin_map.py, перебор порядков)
Секции сверху вниз: A=[B,B] (P2) → M=[B,R,R,B] (P1 + боковой PB) → Z=[B,B,B]
(P0, дно). Колба BLUE квота 6, боковой красный бокс квота 2.
Решение: **PB → P0 → P1 → P2** → колба 7/6, бокс 2/2, потерь 0 (PB строго до
P1!). Ловушка: P0→P1 раньше PB → R,R потеряны → красная квота недостижима →
провал. Перебор 4! = 24 порядка, решение найдено кодом. L100: 8+ штифтов,
смеси 3 цветов, 3 канала.

## S4. Интерактив-спека (З8)
| Объект | Форма-аффорданс | Key-анимации |
|---|---|---|
| Штифт | золотой стержень с кольцом | тап → выдёргивается с дугой + лёгкий скрип, ложится на настил |
| Секция | стеклянный желоб с кристаллами-ромбами | слив: кристаллы сыплются каскадом с подпрыгиванием |
| Отвод | боковой жёлоб с флажком цвета | ведёт в боковой бокс — читается как маршрут |
| Квота | колба/бокс с заполнением | кристалл в колбе + pop; полная — ✓-искра |
| Потеря | кристалл мимо колбы | разбивается о настил осколками + «!» (физическая потеря, не метка) |
| Победа | канал пуст, квоты ✓ | LEVEL COMPLETE + конфетти |

## Рендер-канон (design_system v1.0)
Сеттинг: **кристальный рудник** — тёмный тёплый интервал, деревянные крепи,
фонари, стеклянный канал, вагонетки. Форма поля — вертикальная колонна
(отличает от круга Г4 и прямоугольника Г1-Г3). Промты: tools/sp_pinaway.py;
эталон: tools/pin_map.py. Серия pa1_*.
