## v1.2 — ЗАПРЕЩЁН ОДИН ПРЯМОЙ КОНВЕЙЕР (директива: «опять один конвейер — в
чём смысл и сложность?»)
Пользователь поймал фатал: рендер bj5 — прямая лента + воротa в ряд + рычажки
сбоку. Это НЕ игра: маршрутизация не видна, решений нет (нарушение З0, З2, З13).
КАНОН РЕНДЕРА ТОПОЛОГИИ:
- Лента = ГРАФ ВЕТВЛЕНИЙ, видимый физически: главная линия входит сверху и
  РАЗДВАИВАЕТСЯ на стрелочном переводе S1 (левая/правая ветвь колеи — как
  ж/д стрелка); ветви идут в свои ворота; вторая развилка S2 делит ветвь ещё
  раз. Ворота достижимы РАЗНЫМИ маршрутами (З13).
- Стрелка-указатель стоит РОВНО НАjunction точке и показывает, какая ветвь
  сейчас соединена; тап = перевод стрелки (поворот 90° + дуга + щелчок).
- Пунктир пути идёт ПО ВЕТВЯМ: главная → S1 → выбранная ветвь → ворота.
- ЗАПРЕЩЕНО: прямая лента + рычажки-кружки сбоку; ворота «в ряд» без видимых
  ветвей; стрелка не на точке ветвления.
L1-топология (рендер bj6): S1 делит главную на ЛЕВУЮ (→ BLUE) и ПРАВУЮ
(→ S2), S2 делит правую на GREEN и YELLOW. Сложность L100 — сеть из 10
развилок и 6 ворот (complex_levels.py, bj_L100_map.png).

## v1.1 — РЕНДЕР-КАНОН И СЛОВАРЬ АНИМАЦИЙ (проверено серией bj1–bj4)
З12-инвентарь предметов: лента (позиции блоков) ✓, стрелки-развилки (направление) ✓,
ворота (цвет+кулдаун) ✓ — посредников нет. Стиль: небо-градиент + облака +
парящие кубы (DOF), металлорельсы с бликом, тёмные UI-пилюли, contact shadows.
Словарь анимаций кадра:
- ПРИЦЕЛ: S1 ПУЛЬСИРУЕТ (блок в 2 клетках), палец+рябь, пунктир пути по ленте
  до ворот (эхо-подсветка маршрута), у ворот зелёных — замок кулдауна.
- ПОВОРОТ: дуга-мотион у рычага + щелчок-искра; куб проходит развилку С КРЕНОМ,
  speed-стрики на ленте; следующий блок уже подходит.
- ПРОПУСК: створки ворот раскрываются, куб падает с цветным пуфом, счётчик pop.
- ДЖЕМ: куб вклинился ДИАГОНАЛЬНО в чужие/закрытые ворота, вспышка красным по
  раме ворот, «!»-бейдж, серый дымик, пилюля сердец наклонена + дуги тряски +
  треснувшее сердце + флоатер «−1♥»; S2 на полпути доворота (игрок чинит).
- ПОБЕДА: лента пуста, все ворота открыты с ✓ и СТОПКАМИ рассортированных
  кубов внутри, LEVEL COMPLETE + конфетти, 12/12, 2♥ (цена джема живая).
Палец+рябь — ТОЛЬКО в кадре прицела (в bj3 возвращался из базы — патч-edit).

## S2. Матмодель ядра
**Состояние:** лента (граф путей: ВХОД → развилка S1 → развилка S2 → ворота
G_blue / G_green / G_yellow); очередь блоков (порядок прибытия фиксирован — дизайн-инструмент);
позиции блоков на ленте; направление стрелок S1/S2; счётчики ворот; сердца H=3.
**Действия:** `tap_switch(S)` — поворот стрелки развилки на 90°. Других действий нет (R2).
**Ограничения:** лента НЕ останавливается; блок едет туда, куда смотрит стрелка в
момент прохода развилки; ворота принимают только свой цвет.
**Общее горлышко (З2):** развилки — общий ресурс: переключение готовит СЛЕДУЮЩИЙ
блок, а в хвосте уже едет другой цвет ⇒ решения про порядок взаимодействия.
**Усложнение-кулдаун:** после пропуска блока ворота закрыты на 1 блок — нельзя
слать два подряд в одни ворота ⇒ вынужден чередовать/ждать = каскад планирования (З3).
**Провал:** 0 сердец (3 застрявших чужих блока) или переполнение входа.
**Победа:** все блоки рассортированы (12/12).
**Функция сложности:** интерливинг очереди × кулдаун ворот × число развилок.

## Реализм-фильтр (З9): сортировочный цех — реальное место; стрелки/ворота —
реальные механизмы конвейера. Проходит.

## S3. Уровень L1 (обучающий) — математика
Блоков 12: синих 5, зелёных 4, жёлтых 3. Ворота: G_blue, G_green, G_yellow.
Очередь прибытия: [B, G, B, G, Y, Y, B, G, Y, B, G, B] — интерливинг, при котором
верное решение требует ПЕРЕКЛЮЧАТЬ S1 на каждом втором блоке (никогда два
одинаковых подряд через одну развилку) и держать S2 прямой до 6-го блока.
Скрипт-солвер: Σворот по цветам = Σблоков по цветам ✓ (см. рендер-скрипт).
Идеальная игра: 0 потерь, 0 джемов. Любой невнимательный проход = 1–2 джема = −♥.

## S4. Интерактив-спека (З8: форма = смысл = анимация)
| Объект | Форма-аффорданс | Key-анимации |
|---|---|---|
| Стрелка-развилка S1/S2 | рычаг со стрелой, пульсирует когда блок в 2 клетках | тап → поворот 90° (0.15с) + щелчок; эхо-подсветка пути следующего блока |
| Ворота | створки с цвет-иконкой; открыты для своего цвета | пропуск: створки раскрываются; чужой: мигают красным в момент контакта |
| Блок | глянцевый куб цвета | едет; на развилке лёгкий крен по повороту |
| Джем | блок вклинивается поперёк ворот | «!»-бейдж, −♥ floater, серый дымик |
| Очередь входа | 3 полупрозрачных блока за краем | сдвигаются вперёд при каждом уходе блока |
| HUD | сердца ×3, счётчик «N/12» | сердце гаснет с тряской |
