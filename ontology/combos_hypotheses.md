# Скелеты рынка и гипотезы свободных связок (v1, 2026-08-27)

Из 13 досье + 7 онтологических карточек. Это гипотезы: каждая требует проверки
по сторам (`fetch_game.py` по кандидату-клону) до старта прототипа.

## Четыре доминирующих скелета

### S1. «Канва + Питатели» — $189M+ на тройке
Pixel Flow ($140M) + Yarn Loop ($30.5M) + Sand Loop ($19.1M).
Ядро: пиксель-канва + цветные очереди-питатели снизу + буферы со счётчиками +
маршрутизаторы. Варьируется ТОЛЬКО материал (нити/песок/булавки) и роутинг
(рельсы/иглы/лоток). Все R1–R5 pass, веб-фактор идеальный (дискретная логика).

### S2. «Порядок-блокировки» — $19M / 25.5M dl (Hexa Away) + Car Sort + Loop Sort
Тап-объект летит/едет по фиксированному пути; другие объекты блокируют;
головоломка = порядок выпуска. Бустеры на застреваниях = монетизация.
Веб-фактор идеальный (нулевая физика).

### S3. «Сортировка потока» — Marble Sort $22.6M
Непрерывная лента + приёмники по цвету + тайминг-окна. Лёгкая физика.

### S4. «Процесс-ASMR» — Foodie Sizzle $8.4M / 22.9M dl, Dreamy Room
Пошаговый выбор + сочное физическое действие (раздавить/распаковать) + подача
результата. 3D лоуполи. Терпимо к браузеру.

## Гипотезы свободных связок (кроссовер скелетов × материалы)

- **Г1 [S1 × жидкость]**: канва-питатели, но заливка ЖИДКОЙ краской (растекание
  с уровнем, не сыпучесть). В топах материала «жидкость» в этом скелете нет.
  WebGL: 2D heightfield в шейдере — дёшево. R5: pass (GPU heightfield).
- **Г2 [S2 × S3]**: блоки едут по непрерывной ленте и блокируют друг друга на
  перекрёстках; тап переключает стрелку следующего блока. Сортировка на выходе
  ленты. Ни Car Sort (парковка), ни Marble Sort (шарики) этого не занимают.
- **Г3 [S1 × S2]**: канва собирается из плиток, которые «разлетаются» на месте —
  питатель выпускает плитку по стрелке, путь блокируют уже уложенные.

## Мини-метод проверки гипотезы (перед прототипом)
1. `fetch_game.py "<название-кандидата>"` по 2–3 вероятным клонам → есть ли занятость.
2. Прогон карточки через R1–R5.
3. Санкция человека → прототип ядра за 1 день в Godot (серые кубы).
