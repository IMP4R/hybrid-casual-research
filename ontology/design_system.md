Родилось из директив: «самое главное ориентироваться на стиль референсов»,
«слишком плоско», «ты не распознаёшь все игровые анимации и действия и не
говоришь их в промпте», «логику максимально продумывать, промты максимально
подробные». Проверено на серии sr3/sr4 (Shot Painter). ЭТОТ ФАЙЛ = ЕДИНЫЙ
СТИЛЬ-И ЛОГИК-КАНОН: любой новый концепт и любое исправление старых идут
через него. Источники: research/screens/{sand_loop,pixel_flow,marble_sort},
research/analyses/style_gap.md, research/mockups/STYLE_PROMPTS.md (v3).

## 1. МИР И ГЛУБИНА — МАТЕРИАЛ ЕДИН, СЕТТИНГ У КАЖДОЙ ИГРЫ СВОЙ (правка 2026-08-28)
Директива: «фоны и сеттинг слишком одинаковый. на рефах не так. там дизайн это
только стремление к клэйморфизму». ОБЩЕЕ между играми = только язык МАТЕРИАЛА
(мягкий клэй: пухлые формы, фаски, глянец, мягкие тени). СЕТТИНГ различается:
- Paint Loop — светлая АТЕЛЬЕ-сцена художника: мольберт, баночки, тёплый свет.
- Shot Painter — свой мир пушки-живописца (не клон атеье).
- Belt Jam — СОРТИРОВОЧНЫЙ ЦЕХ: конвейер, металлические направляющие, промзона
  в тёплых тонах, ящики/стеллажи фоном — НЕ небо с облаками.
Небо-градиент с облаками — только там, где сцене уместно небо. Запрещено
копировать один фон во все игры.
Общие материальные правила (внутри своего сеттинга):
- Небо/фон: вертикальный градиент в палитре сеттинга, ярче над центром,
  глубже к углам; задний план уходит в мягкое боке.
- Все объекты: grounded тени + контактная тень там, где встречаются с опорой.
- Небо: вертикальный градиент голубого, ярче над центром, глубже к углам;
  мультяшные облака далеко сзади; НЕСКОЛЬКО глянцевых конфет-кубов парят на
  разной глубине за доской, не в фокусе (DOF/боке). Никаких интерьеров, полок,
  дерева, мебели — мир = воздух + механизм.
- Все объекты: grounded тени + контактная тень там, где встречаются с опорой.

## 2. МАТЕРИАЛ (всегда)
- Глянцевый игрушечный пластик; ВЫСОКАЯ сатурация (no pastel wash);
  specular-блик + светлая верхняя грань + мягкий rim-light на каждой плитке и
  кнопке; фаски (bevel) у всех форм; рендер «Blender-style soft studio».
- Запрещённые слова в промтах: flat solid, airy minimal, cozy workshop,
  wooden, shelves, matte.

## 3. НОСИТЕЛЬ УРОВНЯ
- Большая белая «доска-мольберт»: толстая рама с фаской и бликом по ребру,
  УТОПЛЕННОЕ светлое поле, внутри — бледная точечная сетка (pegboard,
  «незалитая силиконовая форма»). Доска = физический предмет с тенью.

## 4. КАРТИНКА-ЦЕЛЬ (главный урок референсов)
- Уровень = УЗНАВАЕМЫЙ пиксель-объект (попугай, арбуз, предмет), собранный из
  ВОКСЕЛЬ-КУБОВ; силуэт читается с первого взгляда ДО начала игры.
- Пустая клетка = тот же воксель-юнит в режиме ghost: утопленный слот с бледным
  полупрозрачным кубом своего будущего цвета. Заполненная = сочный глянцевый
  куб. Контраст ghost/сочный — награда и прогресс (З6).
- ЕДИНЫЙ ЮНИТ ФОРМ: снаряды, плитки очереди и клетки — один и тот же
  скруглённый куб (форма = роль, З8).

## 5. UI (инверсия ранней ошибки)
- Пилюли ТЁМНО-синие 3D с белым жирным текстом и тонкой тёмной обводкой;
  круглые кнопки с глянцем; сердечки/монета/шестерёнка — крупные, читаемые.
- Счётчик прогресса под механизмом; лоток/очередь снизу отдельной белой пилюлей.

## 6. СЛОВАРЬ АНИМАЦИЙ (З8 — в каждый промт кадра)
- ВЫСТРЕЛ: отдача корпуса (лёгкий клевок назад, колёса приседают), вспышка
  «звезда» у дула, 2 серых колечка дыма, снаряд уже летит.
- ОТСКОК: жёлтая звезда вспыхивает КРУПНЕЕ с радиальными искрами ровно на раме.
- ПОЛЁТ: снаряд строго по своему прямому сегменту, шлейф-искры назад по линии.
- УСПЕХ: впечатывание заподлицо + белый ✓-бейдж в углу клетки + радиальные
  лучи + тонкое пыльное кольцо + pop счётчика.
- РАСКОЛ: звезда удара + осколки цвета с вращением + крошка + красный ✕ рядом.
- УРОН: пилюля сердец наклоняется, дуги тряски, третье сердце серое с
  трещиной, флоатер «−1♥» у пилюли.
- ОЧЕРЕДЬ: кубы сдвигаются, новый въезжает справа с motion-streak.
- ПОБЕДА: золотая лента LEVEL COMPLETE, конфетти, последние лучи на новой
  клетке, механизм расслаблен.
- Тап-палец + рябь — ТОЛЬКО в кадре прицела (до действия).

## 7. ЛОГИКА-КАНОН (максимальная проработка — директива)
- Матмодель до арта: состояние → действия → ограничения → горлышко → победа
  (З0). Солвер/скрипт обязателен для уровня-эталона.
- КАЖДЫЙ кадр = МОМЕНТ действия с его анимацией; состояния выводятся из
  анимаций, не наоборот.
- Непрерывность серии: счётчики, сердца, очередь, поворот корпуса механизма к
  новой цели — арифметически и физически сходятся между кадрами.

## 8. ПРОМТ-КАНОН (максимальная подробность — директива)
- До генерации: эталон-карта в Pillow (координаты клеток, ломаные, изломы) —
  единственный источник геометрии; проверка глазами.
- В промте: позиции фракциями/сторонами («55% высоты правой рамы»), перечень
  перелетаемых клеток и клетки-цели, материал, свет, тени, UI, анимации
  момента, запрет кривых (для траекторий: «two straight ruler segments»).
- Серия: edit-chain от одобренной базы; в каждом edit перечислить что НЕ менять.

## 11. ПОЛИТИКА ПРОМТОВ v2 — DATA-DRIVEN (2026-08-28, после «одного конвейера»)
Причина: промты, написанные прозой по памяти, систематически теряли элементы
игровой логики (дуга вместо рикошета, прямой конвейер вместо развилок, кран,
отсутствие поворота пушки). ПРАВИЛО:
1. Топология/раскладка уровня = СТРУКТУРА ДАННЫХ в коде (как beltjam_topology.py:
   узлы, ветви, ворота; parrot_map.py: клетки, лучи).
2. Из данных генерируется И Pillow-эталон, И текст промта — один источник правды.
   Элемента нет в данных = его нет ни в игре, ни в промте.
3. Таблица соответствия «элемент матмодели → физический носитель в кадре → фраза
   промта» обязательна до генерации: состояние → объект, действие → анимация,
   ограничение → видимый признак (замок/кулдаун/полоска).
4. Чек-лист перед отправкой: топология видна физически (ветви/изломы/уровни);
   посредников нет (З12); палец только в прицеле; непрерывность серии; сеттинг
   своей игры; banned words отсутствуют.
5. После генерации — верификация глазами ПО ТОМУ ЖЕ чек-листу; нарушение =
   точечный патч-edit, не полная перегенерация.
