# Hybrid-Casual Research Pipeline

Методические документы и инструменты исследования hybrid-casual игр и подготовки ассетов.

## Состав

- `METHOD.md`
- `PLAN.md`
- `PUBLICATION.md`
- `SOURCE-FILES.txt`
- `ontology`/
- `research`/
- `tools`/
- `workbench.md`

## Подготовка и запуск

Не импортируйте и не запускайте незнакомые модули автоматически: возможны сетевые запросы, платежные операции и другие внешние эффекты. Отсутствующие данные, сервисы и конфигурацию нужно подготовить самостоятельно.

## Ограничения снимка

- Source tools and method documents; reference binaries, secrets and run data excluded; runtime unverified.
- При оформлении репозитория приложение не развёртывалось, платежи и внешние API не запускались; тесты не перепроверялись.
